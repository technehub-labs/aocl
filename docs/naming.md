# Naming & identity

**Status:** draft (v0.1.0)

Three unrelated-in-scope initiatives share the letters MAMA. This repository — **AOCL** — is a fourth thing. Keeping them distinct is a correctness requirement, not pedantry:

| # | Identity | Expansion | Scope | Home |
|---|---|---|---|---|
| 1 | **MAMA** (TechNE Hub project) | Measuring and Managing Autonomy | The industry project whose asset family (GB1040, GB1042/A, GB1054, GB1075, IG1219, IG1291A, IG1550, IG1552…) includes the source document of this toolkit | TechNE Hub |
| 2 | **`mama`** (lowercase, code-formatted) | measuring and managing autonomy | An autonomy method for **decision-rights grants**: six-dimension profiles, autonomy contracts, ledgers | [`emmanuel-a-otchere/measuring-and-managing-autonomy`](https://github.com/emmanuel-a-otchere/measuring-and-managing-autonomy) |
| 3 | **MAMA** (umbrella organization) | Measuring Automation & Measuring Autonomy | An umbrella framework organization for automation measurement + autonomy governance | [Measuring-Automation-Managing-Autonomy](https://github.com/Measuring-Automation-Managing-Autonomy) |
| 4 | **AOCL** (this repo) | Autonomous Operations & Closed Loops | **Closed-loop automation maturity**: loop levels L1–L5, assessment vectors, realization heuristic, loop modeler | this repository |

## The interlock and the boundary

The source document's own MAMA definition — "a comprehensive and systematic approach that empowers organizations to embark on autonomous operation projects with confidence, employing a closed-loop methodology from project definition to value realization" (GB1040) — makes closed loops the *methodology* spine. AOCL formalizes that spine's **loop-maturity** instrument.

`mama` (identity 2) measures **delegated decision authority** (what a unit may decide, at what level, under which guardrails). AOCL measures **how mature a feedback loop is** (how sophisticated its goal decisioning, data veracity, and feedback intelligence are). A loop can be L5 and still operate within an L2 autonomy grant; a highly-autonomous unit may run only L1 loops. The instruments interlock (the loop operates *inside* the granted authority) but the scores are never merged, averaged, or mapped 1:1.

## Rules for anything published under this repository

1. First reference: *"AOCL (Autonomous Operations & Closed Loops) formalizes the TechNE Hub guide of the same name; it is distinct from the lowercase `mama` autonomy method and from the MAMA umbrella organization."*
2. `mama` is always lowercase in code formatting; MAMA (projects 1 and 3) is always uppercase.
3. No composite "AOCL-MAMA score". Loop levels and autonomy grant levels are never aggregated.
4. References to `mama` always point to its canonical home (identity 2's URL above).
